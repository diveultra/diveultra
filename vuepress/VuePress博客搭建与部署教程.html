# 使用 VuePress 搭建个人博客并部署

# 1. 什么是 VuePress

VuePress 是由 Vue.js 驱动的静态网站生成器，适用于文档、博客等内容呈现场景。它支持 Markdown 写作，并可通过 Vue 扩展强大功能。

# 2. 环境准备与安装

  • Node.js (推荐16及以上) 下载安装：nodejs.org (opens new window)
  • npm/yarn 包管理器
  • 全局安装 vuepress
npm install -g vuepress@next # VuePress 2.x

# 3. 初始化博客项目

在你的工作目录下运行：

mkdir my-blog && cd my-blog
npm init -y
npm install vuepress@next

目录结构示例：

my-blog/
  docs/
    README.md
  package.json

修改 package.json 的 scripts：

"scripts": {
  "docs:dev": "vuepress dev docs",
  "docs:build": "vuepress build docs"
}

# 4. 编写与组织文章

  • 所有文章默认放在 docs/ 内，可以按照分类建子目录。
  • 首页建议使用 docs/README.md。
  • 其他页面如：docs/about/README.md、docs/技术/xxx.md

# 5. 本地预览与构建

npm run docs:dev   # 本地开发预览
npm run docs:build # 生成静态文件到 docs/.vuepress/dist

# 6. 图片引用与展示问题解决

📖 详细教程： 请查看 [VuePress 图片在 GitHub Pages 上正常显示完整教程](./VuePress图片在GitHub Pages上正常显示完整教程.md)

# a. 图片正确存放方法

  • 推荐方案： 使用 docs/.vuepress/public/images/ 目录统一存放图片
  • 在 Markdown 中使用绝对路径引用：![描述](/images/xxx.png)
  • 不要使用绝对路径或本地磁盘路径，也不要引用 GitHub 的 raw 路径。

# b. 自动化脚本（推荐）

项目已集成自动化脚本，可以一键处理图片路径：

# 发布前：准备图片路径（处理指定目录）
npm run blog:prepare -- docs/english

# 发布后：恢复本地路径（Typora 可正常显示）
npm run blog:restore

工作流程：

  1. 日常写作：使用 Typora，图片自动保存到 .assets 目录，相对路径引用
  2. 发布前：执行 blog:prepare，自动转换为 /images/xxx.png 格式
  3. 构建部署：npm run build && npm run deploy
  4. 发布后：执行 blog:restore，恢复本地相对路径

# c. 部署后图片无法显示的常见原因及解决

  • 原因1：图片未被正确编译到 dist
    • 确保图片在 public/images/ 目录，构建时会自动复制
  • 原因2：路径不对
    • 使用绝对路径 /images/xxx.png，不要用相对路径
  • 原因3：GitHub Pages 自动 ignore 一些文件
    • 图片名称尽量使用英文及数字，避免特殊字符
    • 不要把图片放在 .gitignore 忽略的目录

# d. 其他方案：图床（可选）

  • 推荐使用 GitHub Issues + PicGo 把图片上传，引用 https://user-images.githubusercontent.com/xxx/xx.png 直链
  • 更高阶可用腾讯云 COS、七牛云等

# 7. 部署到 GitHub Pages

# a. 推送代码到 GitHub

  1. 新建仓库，将博客代码上传。
  2. 确保静态页面输出目录为 docs/.vuepress/dist 或根目录 docs/

# b. 设置自动部署

  • 方式1：本地构建后，手动把 dist 目录下内容推到 gh-pages 分支。
  • 方式2：用 GitHub Actions 自动化（推荐）
# .github/workflows/deploy.yml 示例
name: Deploy VuePress site to GitHub Pages
on:
  push:
    branches:
      - main
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      - run: npm ci
      - run: npm run docs:build
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: docs/.vuepress/dist

完成后，配置 GitHub Pages 指向 gh-pages 分支下的 / 目录即可。

# 8. 部署到个人服务器

  • 方法一：scp/sftp 复制 dist 目录内容到你的服务器 Nginx/Apache 目录下即可
scp -r docs/.vuepress/dist/* user@your.server.ip:/var/www/html/
  • 方法二：服务器上用 Docker/Nginx 反代更灵活，可根据自身需求配置
